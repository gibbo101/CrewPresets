Save named groups of colonists, animals and mechs - "Mining Crew", "Strike Team", "Pack Train" - and apply them with one click in pawn-selection dialogs, instead of hand-picking the same pawns every time.

Works with the vanilla selection dialogs, so it helps every launch and departure: transporters and shuttles (including modded craft), caravans, caravan splitting, pit-gate entry and gravship launches.

FEATURES
- Save the current selection as a named group from inside any supported dialog.
- Apply a group with one click.
- Build groups on a screen that shows what you are choosing: every pawn's skills, passions and equipped weapon, laid out like the Work tab.
- Click a skill column to sort by it - your best cook, or your best shooter, straight to the top.
- Drag down the tick column to add or remove a run of pawns in one sweep.
- Groups are stored in the save file, like bills.

WHAT'S NEW IN 1.0.1
- New member screen: choose from the whole colony with skills, passions and equipped weapons on show, instead of a list of bare names.
- Sortable skill columns on both group screens, and each group remembers its own sort.
- A tick/cross column you can drag along, the same way you set work priorities.
- Changes are saved with the Done button, so closing the window discards them.
- Optional skill entries in the "Sort by" dropdown of the transporter, shuttle, caravan and portal dialogs. On by default, switchable in mod settings.
- Updated to Multiplayer API 0.6.

MULTIPLAYER
Built with the Multiplayer mod in mind; group changes are synced. Runs fine without Multiplayer installed.
